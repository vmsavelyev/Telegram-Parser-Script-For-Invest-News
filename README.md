# Telegram-Parser-Script-For-Invest-News

Скрипт для консоли браузера, который выгружает текст сообщений из открытого канала/чата в веб-версии Telegram (Web K, web.telegram.org/k) в виде таблицы с колонками «Надо брать», «Текст сообщения», «Дата», «Время», «Канал», «Тайминг». Удобно для сбора инвестиционных новостей из Telegram-каналов в единый датасет. Колонка «Надо брать» проставляется автоматически по ключевым словам — помогает сразу отсеять новостной шум.

Результат копируется в буфер обмена в формате TSV (значения разделены табуляцией) — можно сразу вставить в Excel/Google Таблицы.

## Как использовать

1. Откройте канал или чат в веб-версии Telegram: https://web.telegram.org/k/
2. **Долистайте вручную до самого начала переписки** (до первых сообщений). Скрипт скроллит ленту вниз и соберёт только то, что идёт после текущей позиции.
3. Откройте консоль разработчика (в Chrome/Edge — `F12` или `Cmd+Option+J` на macOS) и перейдите на вкладку **Console**.
4. Скопируйте содержимое файла [`Parser-Script`](Parser-Script) целиком и вставьте в консоль, затем нажмите Enter.
5. В появившемся окне введите:
   - дату в формате `ДД.ММ.ГГГГ` — она будет проставлена всем собранным сообщениям, **или**
   - слово `авто` — тогда для каждого сообщения будет использована его настоящая дата и время публикации.
6. В правом верхнем углу экрана появится панель с индикатором прогресса. Скрипт будет автоматически скроллить ленту и собирать сообщения.
7. Чтобы остановить сбор раньше (например, если собрали уже достаточно), нажмите кнопку **«Остановить и выгрузить»** на панели. Если не останавливать — скрипт сам завершится, когда дойдёт до конца ленты.
8. По завершении результат автоматически скопируется в буфер обмена, появится сообщение с количеством собранных сообщений. Если браузер заблокировал доступ к буферу обмена — на экране появится текстовое поле, из которого нужно скопировать данные вручную (`Ctrl+C`).

## Формат результата

```
Надо брать	Текст сообщения	Дата	Время	Канал	Тайминг
Важно	Текст первой новости	19.08.2026	14:32	Название канала	19.08.2026 14:32:00
Возможно	Текст второй новости	19.08.2026	14:47	Название канала	19.08.2026 14:47:00
```

- «Канал» — название открытого канала/чата, определяется один раз в начале сбора по заголовку окна чата.
- «Тайминг» — дата и время сообщения в едином формате `ДД.ММ.ГГГГ Ч:ММ:СС`. Секунды известны только в режиме «авто» (берутся из `data-timestamp`); при ручной дате и при отсутствии timestamp секунды проставляются как `00`.
- «Надо брать» — автоматическая метка важности новости, одна из трёх: `Важно`, `Не важно`, `Возможно` (всё, что не попало под явные правила `Важно`/`Не важно`). Проставляется функцией `classifyImportance()` по ключевым словам и паттернам в тексте сообщения:
  - **Важно** — отчётность МСФО/РСБУ российских публичных компаний, ключевая ставка ЦБ РФ, санкции, НАТО, конфликт на Украине, IPO, размещение ОФЗ, выступления Путина, Пескова, фон дер Ляйен и другие геополитические комментарии.
  - **Не важно** — итоги/события дня и прочая не биржевая информация, факт курса валют без контекста, движение акции/индекса пост-фактум без новости, мнения зарубежных инвестдомов, зарубежные макро-индексы (PMI, ISM, CPI и т.п.) и отчётность крупных зарубежных компаний.
  - Разметка основана на ключевых словах и субъективна по своей природе — при необходимости донастройте списки паттернов в начале функции `classifyImportance()` (константы `IMPORTANT_PATTERNS`, `FOREIGN_BANKS`, `FOREIGN_MACRO`, `FOREIGN_COMPANIES` и т.д.) под свой набор каналов.

## Особенности и ограничения

- Скрипт рассчитан на веб-версию Telegram **K** (`web.telegram.org/k`). В версии A (`web.telegram.org/a`) вёрстка отличается, работоспособность не гарантируется.
- Служебные сообщения, разделители дат и спонсорские посты пропускаются автоматически.
- Дедупликация сообщений происходит по `data-mid` (внутренний идентификатор сообщения в Telegram), либо по паре «время + текст», если идентификатор недоступен.
- В режиме «авто» дата берётся из `data-timestamp` сообщения; если атрибут недоступен, дата определяется по ближайшему разделителю-дате в ленте (например, «19 августа»).
- Скрипт ничего не отправляет на сторонние сервера — весь сбор и обработка происходят локально в браузере.
- Скорость прокрутки и сбора настраивается константами в начале файла скрипта (`SCROLL_RATIO`, `TICK_MS`, `IDLE_TICKS`, `MIN_WAIT_MS`, `MAX_WAIT_MS`). Если на медленном интернете или в большом канале скрипт начнёт пропускать сообщения, в первую очередь уменьшите `SCROLL_RATIO` (шаг скролла) — это самый рискованный параметр.
