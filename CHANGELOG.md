# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Исправлено
- В режиме «авто» дата сообщения без атрибута `data-timestamp` больше не подменяется датой по умолчанию, введённой пользователем: скрипт ищет ближайший разделитель-дату в ленте (например, «19 августа») и парсит из него реальную дату.
- Ключ сортировки собранных сообщений больше не смешивает unix-время (`data-timestamp`, секунды) и внутренний идентификатор сообщения (`data-mid`) — для сообщений без `timestamp` используется отдельный числовой диапазон, чтобы не нарушать порядок строк в выгрузке.
- Символы табуляции внутри текста сообщения теперь заменяются на пробел, чтобы не ломать столбцы в TSV-формате результата.

### Добавлено
- Проверка формата вручную введённой даты (`ДД.ММ.ГГГГ`) с предупреждением, если формат некорректен.
- Предупреждение в стартовом диалоге о необходимости долистать канал до самого начала переписки перед запуском (скрипт скроллит ленту вниз).

## [1.0.0] — 2026-09-12

### Добавлено
- Первая версия скрипта для сбора сообщений из веб-версии Telegram (Web K).
- Автоматический поиск скроллируемого контейнера с сообщениями.
- Сбор текста, даты и времени сообщений с дедупликацией по `data-mid`.
- Режимы простановки даты: фиксированная дата для всех сообщений или реальная дата каждого поста («авто»).
- Панель прогресса с возможностью досрочной остановки сбора.
- Копирование результата в буфер обмена в формате TSV с fallback на текстовое поле, если доступ к буферу обмена заблокирован браузером.
